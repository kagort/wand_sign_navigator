# Путеводитель по книге «Блуждающие значения»

> Служебная заметка для работы в Obsidian. На сайт не публикуется (`draft: true`).
> Главная страница сайта — `index.md`.

## Где что лежит

Настоящая папка проекта — `content/` в git-репозитории `wand_sign_navigator`.
В хранилище Obsidian она подключена ссылкой (junction):

```
C:\Users\Пользователь\wand_sign_navigator\content              ← настоящая папка (git)
C:\OBSIDIAN\new-vault\00 Projects\03 wand_sign_navigator  ──►  ссылка на неё (видит Obsidian)
```

Личные заметки хранилища в репозиторий не попадают: публикуется только `content/`.

```
content/
├── 00-meta/        конвенции проекта (konventsii.md)
├── 01-concepts/    карточки понятий           type: концепт
├── 02-metaphors/   метафоры и образы          type: метафора
├── 03-people/      персоналии (+ assets/ с портретами)   type: персоналия
├── 04-cases/       развёрнутые примеры        type: пример-кейс
├── 05-chapters/    хабы глав (список разделов)   type: хаб-главы
│   └── razdely/chapter_N/   страницы разделов   type: раздел-главы
├── 06-context/     фоновый контекст (+ assets/)          type: контекст
├── index.md        главная страница сайта, оглавление
└── README.md       эта заметка
```

Поля frontmatter, статусы (`draft` / `reviewed` / `final` / `excluded`) и типы связей описаны в
[[konventsii|Конвенциях проекта]].

## Как работать в Obsidian

1. **Перед началом:** в папке репозитория выполнить `git pull origin v5`.
2. Новая карточка — в папку своего типа (см. схему выше), имя файла латиницей через дефис,
   поле `id` = имя файла. Шаблон — через Templater (Folder templates для `01-concepts`, или вручную).
3. На каждую главу — хаб `05-chapters/chapter_N.md` со списком разделов; на каждый раздел — страница
   `05-chapters/razdely/chapter_N/chapter_N_<номер>.md` с аннотацией и списком карточек.
   В карточках ссылайтесь на раздел: `[[chapter_3_vi|Гл. 3 (vi) Перегруженные содержания]]`.
4. Переименовывать и перемещать файлы только в Obsidian — он обновит wiki-ссылки.
5. Заметка, которую не нужно публиковать: `draft: true` во frontmatter
   (или `status: excluded` + `exclude_reason`).
6. **После работы:**
   ```powershell
   cd $env:USERPROFILE\wand_sign_navigator
   git add content
   git commit -m "Карточки гл. N: …"
   git push origin v5          # сайт пересоберётся автоматически
   ```

Таблица персоналий и данные для дашбордов собираются из карточек:
`python scripts/build_dataset.py` → `data/people.xlsx`, `data/*.json` (поля — в [[konventsii|Конвенциях]]);
`python scripts/build_chapter_index.py` → сводка и список всех карточек в хабах глав (`05-chapters/chapter_N.md`, `predislovie.md`);
`python scripts/build_dashboards.py` → `quartz/static/dash/linia.html` («Линия книги») и `quartz/static/dash/atlas.html`
(«Атлас персоналий»); на сайте — `/static/dash/linia` и `/static/dash/atlas` (старые адреса `/linia/`, `/atlas/` перенаправляют).
Шаблоны — `dashboards/*.template.html`; библиотеки лежат в `quartz/static/dash/vendor/`, поэтому дашборды работают и без интернета
(без интернета нет только подложки карты и веб-шрифтов).
При каждом push в `v5` это делается автоматически перед сборкой сайта.

Посмотреть сайт локально (с поиском, графом и дашбордами): `npx quartz build -d content --serve` → http://localhost:8080.
Открывать HTML-файлы из `public/` двойным щелчком нельзя: граф и поиск так не загружаются.

Подробно про синхронизацию и что делать при конфликте — `docs/SYNC.md` в репозитории,
журнал сессий — `docs/Progress.md`.
